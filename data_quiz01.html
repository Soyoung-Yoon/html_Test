문제 1 / 3
기존의 확률변수 X를 aX + b (단, a > 0)로 선형 변환(Linear Transformation)하였을 때, 그 값이 변하지 않는 통계량은?
1 왜도 (Skewness)
2 표준편차 (Standard Deviation)
3 평균 (Mean)
4 중앙값 (Median)
💡 핵심 개념
왜도(Skewness)와 첨도(Kurtosis)는 분포의 '형태(Shape)'를 나타내는 통계량입니다. 데이터를 일정 비율로 늘리거나(a) 이동시켜도(b) 분포의 비대칭 구조는 유지됩니다.
단, a < 0이면 왜도의 부호가 반전됩니다. 이 문제는 a > 0 조건이므로 왜도가 완전히 그대로 유지됩니다.
📋 오답 선지 분석
② 표준편차
SD(aX + b) = |a| · SD(X)척도(a)에 비례하여 변함 — b는 영향 없음
③ 평균
E(aX + b) = a · E(X) + b척도(a)와 이동(b) 모두 영향을 받음
④ 중앙값
Median(aX + b) = a · Median(X) + b척도(a)와 이동(b) 모두 영향을 받음

문제 2 / 3
두 확률변수 X와 Y의 상관계수가 0.5일 때, 다음 중 올바른 설명은?
1 −X와 Y의 상관계수는 0.5이다.
2 X+0.1과 Y의 상관계수는 0.6이다.
3 X와 2Y의 상관계수는 1이다.
4 X+0.3과 Y+0.2의 상관계수는 0.5이다.
💡 핵심 공식
선형변환된 두 변수의 상관계수:
ρ(aX + b, cY + d) = sign(a · c) × ρ(X, Y)

이동항(b, d)은 상관계수에 전혀 영향을 주지 않습니다.
척도항(a, c)은 크기는 보존하고, 두 척도의 부호곱이 음수이면 부호만 반전됩니다.
📋 각 선지 분석
① 오답 (−0.5)
ρ(−X, Y): a=−1, c=1 → sign(−1×1) = −1부호곱이 음수 → 상관계수 부호 반전: 0.5 × (−1) = −0.5
② 오답 (0.5)
ρ(X+0.1, Y): b=0.1은 이동항 → 상관계수 불변이동은 영향 없음. 결과는 0.6이 아닌 그대로 0.5
③ 오답 (0.5)
ρ(X, 2Y): a=1, c=2 → sign(1×2) = +1, 크기 보존양의 척도 배는 크기에 영향 없음. 결과는 1이 아닌 그대로 0.5
④ 정답 (0.5)
ρ(X+0.3, Y+0.2): 이동항만 있음 (a=1, c=1)이동은 영향 없음. sign(1×1)=+1 → ρ 그대로 0.5 ✅
문제 3 / 3
X와 Y의 상관계수가 0.2일 때, −2X + 3과 Y − 1의 상관계수는?
1 −0.2
2 0.2
3 −0.4
4 0.4
💡 풀이
ρ(−2X + 3, Y − 1)을 구하는 과정:

① 이동항 제거: +3과 −1은 상수 이동 → 상관계수에 영향 없음
② 척도항 확인: −2X의 척도 a = −2, Y의 척도 c = +1
③ 부호곱 계산: sign(a · c) = sign(−2 × 1) = sign(−2) = −1
④ 결과: ρ = (−1) × 0.2 = −0.2
📋 오답 선지 분석
① 정답 (−0.2)
sign(−2 × 1) = −1, 크기 보존−2는 음수 → 부호 반전, 절댓값 2는 크기에 영향 없음 ✅
② 오답 (0.2)
부호 반전을 무시한 경우a = −2임을 간과하여 그대로 0.2로 계산한 오류
③ 오답 (−0.4)
|a| = 2를 크기에도 반영한 경우상관계수는 −1과 1 사이로 스케일이 변하지 않음. 0.2 × 2 ≠ 적용 불가
④ 오답 (0.4)
부호 반전 무시 + 크기 잘못 반영두 가지 오류 동시 발생
📐 공식 정리
변환 형태계산 결과이유
ρ(aX+b, cY+d)sign(a·c) × ρ(X,Y)이동 무관, 척도 부호만 반영
a > 0, c > 0+ρ(X,Y)부호 유지
a < 0 또는 c < 0 (한쪽)−ρ(X,Y)부호 반전
a < 0, c < 0 (양쪽)+ρ(X,Y)음×음=양, 부호 유지
