문제 1 / 3
의사결정나무(Decision Tree) 모델에서 분할 기준(Split Criterion)으로 사용되는 지니 지수(Gini Index)와 엔트로피 지수(Entropy Index)에 대한 계산 문제이다. 어떤 노드에 속한 두 클래스의 데이터 수가 각각 Y = 10, X = 0일 때, 이 노드의 지니 지수와 엔트로피 지수를 순서대로 바르게 나열한 것은?
1 1, 1
2 1, 0
3 0, 1
4 0, 0
💡 핵심 개념
지니 지수와 엔트로피 지수는 모두 노드의 불순도(Impurity)를 측정하는 지표로, 한 노드가 하나의 클래스로만 이루어진 순수 노드(Pure Node)일 때 두 값 모두 최솟값인 0이 됩니다.
Y = 10, X = 0이라는 것은 두 클래스 중 X 클래스가 전혀 없는, Y로만 이루어진 완전한 순수 노드를 의미합니다.
📋 오답 선지 분석
① 오답 (1,1)
두 지표의 최댓값과 혼동한 경우두 클래스 비율이 각각 0.5로 균등할 때 불순도가 최대가 되며, 이때도 지니 지수는 1이 아닌 0.5입니다
② 오답 (1,0)
Gini = 1 − Σpᵢ² = 1 − (1² + 0²) = 0순수 노드의 지니 지수를 잘못 계산한 경우 (정답은 0)
③ 오답 (0,1)
Entropy = −Σpᵢlog₂(pᵢ) = −(1·log₂1 + 0·log₂0) = 00·log₂0은 정의상 0으로 처리하므로 엔트로피도 0입니다

문제 2 / 3
다차원척도법(Multidimensional Scaling, MDS)에 대한 설명으로 가장 옳지 않은 것은?
1 개체들 간의 유사성(또는 비유사성) 정보를 이용하여 개체들을 저차원 공간상에 점으로 시각화하는 분석 기법이다.
2 계량적 MDS는 구간척도나 비율척도와 같은 연속형 데이터에 적용하며, 개체 간의 실제 거리를 계산하여 공간상에 표현한다.
3 비계량적 MDS는 개체 간 유사성이 순서척도로 측정된 경우에 사용하며, 순위 정보만을 보존하도록 배치한다.
4 데이터 분석을 통해 개체들 간의 비유사성을 측정하고, 이를 기준으로 서로 유사한 개체들을 하나로 묶어 다수의 동질적인 그룹을 형성하는 것을 주된 목적으로 한다.
💡 핵심 개념
다차원척도법(MDS)의 목적은 개체 간의 비유사성(거리) 정보를 최대한 보존하면서 개체들을 저차원(2~3차원) 공간상의 '점(Coordinate)'으로 배치하여 전체적인 관계 구조를 시각적으로 파악하는 것입니다.
개체들을 그룹으로 묶어 군집(Cluster)을 형성하는 것은 MDS가 아니라 군집분석(Cluster Analysis)의 목적입니다.
📋 각 선지 분석
① 옳은 설명
유사성 정보 → 저차원 공간의 점으로 시각화MDS의 기본 정의에 해당
② 옳은 설명
계량적 MDS: 연속형 데이터, 실제 거리(Euclidean 등) 사용구간·비율척도에 적용되는 계량적 MDS의 정확한 설명
③ 옳은 설명
비계량적 MDS: 순서척도, 순위 정보만 보존서열척도로 측정된 유사성에 적용되는 비계량적 MDS의 정확한 설명
④ 정답 (틀린 설명)
동질적 그룹(Cluster) 형성이 목적 → 군집분석의 설명MDS는 점으로 '배치'하여 관계 구조를 파악하는 것이 목적이며, 그룹으로 '묶는' 것은 군집분석의 역할 ✅

문제 3 / 3
서포트 벡터 머신(Support Vector Machine, SVM)에 대한 설명으로 가장 옳지 않은 것은?
1 데이터들을 분리하는 여러 후보 평면 중, 두 클래스 간의 거리를 나타내는 마진을 최대화하는 방향으로 최적의 초평면을 찾아 학습한다.
2 결정 경계를 설정할 때 모든 데이터 포인트를 고려하는 것이 아니라, 결정 경계에 가장 가까이 위치한 일부 데이터 포인트인 '서포트 벡터'들 간의 거리만을 직접 계산하여 사용한다.
3 선형 분리가 불가능한 비선형 데이터의 경우, 커널 함수를 적용하여 원래의 고차원 데이터를 선형 분리가 용이한 저차원 공간으로 변환하여 문제를 해결한다.
4 서포트 벡터 머신은 분류 문제뿐만 아니라 회귀 분석 문제에도 적용할 수 있으며, 데이터에 노이즈나 이상치가 존재할 때 마진을 조정하는 소프트 마진 방식을 활용할 수 있다.
💡 핵심 개념
커널 트릭(Kernel Trick)은 원래 차원에서 선형 분리가 불가능한 데이터를 저차원에서 고차원 공간(High-dimensional Space)으로 매핑(변환)하여 선형 분리가 가능하도록 만드는 기법입니다.
'고차원 데이터를 저차원 공간으로 변환'한다는 설명은 방향이 반대로 되어 있는 틀린 설명입니다.
📋 각 선지 분석
① 옳은 설명
마진 최대화 → 최적 초평면 탐색SVM의 기본 학습 원리
② 옳은 설명
결정 경계에 가장 가까운 서포트 벡터만 사용SVM이 전체 데이터가 아닌 일부 포인트에만 의존하는 특징
③ 정답 (틀린 설명)
커널 함수: 저차원 → 고차원 매핑 (방향이 반대로 서술됨)비선형 데이터를 고차원 공간으로 보내야 선형 분리가 용이해짐 ✅
④ 옳은 설명
분류·회귀 모두 적용 가능, 소프트 마진으로 이상치 허용SVR(회귀)과 소프트 마진에 대한 정확한 설명
